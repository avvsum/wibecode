## Что такое Blender

[Blender](https://www.blender.org/) — отдельная программа для работы с трёхмерными сценами:
объектами, камерой, материалами и анимацией. В ShortsStudio она рисует кадры готовой студии.
Workbench — встроенный в Blender движок рендера, который используется в этом проекте.
Blender устанавливается отдельно от Python-зависимостей; пакет `bpy` ставить не нужно.

## Как работает наш движок

1. Claude превращает описание в JSON. Для реплики используется сцена `say`:
   персонаж `robot` или `girl`, текст, начало, конец и план `wide`, `medium` или `close`.
2. Приложение проверяет JSON и делит временную шкалу на студию и плоские вставки.
3. В фоне запускается Blender со скриптом `src/core/render3d/blender_scene.py`.
   Скрипт создаёт студию и персонажей, выбирает камеру и анимирует движения и рот.
4. Blender сохраняет PNG-кадры студии в разрешении **810 × 1440**.
   Текст, изображения и графики готовятся отдельно через Pillow.
5. FFmpeg увеличивает кадры до **1080 × 1920**, добавляет субтитры и собирает MP4 с **30 fps**.
   Готовый файл публикуется после успешной сборки; временные кадры удаляются.

Сцена и персонажи заданы кодом: описание управляет репликами и планами камеры,
но не создаёт произвольные 3D-модели. Озвучки в текущей версии нет.

## Запуск через окно

Выполни [быстрый старт](../README.md#быстрый-старт), установи Blender 4.2+ и FFmpeg.
Если `blender --version` не работает, укажи настоящий путь к исполняемому файлу:

```powershell
$env:WIBECODE_BLENDER = "C:\Program Files\Blender Foundation\Blender 5.0\blender.exe"
& $env:WIBECODE_BLENDER --version
.\.venv\Scripts\python.exe -m src.ui.main
```

Команды выполняются в одном PowerShell из корня проекта. Путь выше — пример:
замени его на путь к своей версии. Если окно приложения уже открыто, перезапусти его
из этого PowerShell, чтобы оно получило переменную окружения.

Выбери **3D**, опиши короткий диалог робота и девушки, нажми **«Рендер»**.
Начни с 5–6 секунд: каждая секунда студии требует 30 отдельных кадров.
Blender открывать вручную не нужно. Путь к результату появится в строке состояния.

## Запуск из Python без Claude и API-ключа

Когда JSON уже готов, нужен только локальный рендер. Сохрани пример в `render_3d.py`
в корне проекта и запусти `.\.venv\Scripts\python.exe render_3d.py` из того же PowerShell:

```python
import json
from src import api

spec = api.parse_spec(json.dumps({
    "duration": 4,
    "render_mode": "3d",
    "scenes": [
        {"type": "say", "who": "robot", "shot": "close",
         "text": "Привет! Это наш первый 3D-ролик.", "start": 0, "end": 4}
    ]
}))
print(api.render_video(spec, "outputs/first-3d.mp4"))
```

Если приложение сообщает «Blender не найден», проверь PATH или `WIBECODE_BLENDER`.
Если не найден FFmpeg, проверь `ffmpeg -version` в том же PowerShell.
