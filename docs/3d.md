## Что такое Blender

[Blender](https://www.blender.org/) — отдельная программа для работы с трёхмерными сценами:
объектами, камерой, материалами и анимацией. В ShortsStudio она рисует кадры готового окружения.
Workbench — встроенный в Blender движок рендера, который используется в этом проекте.
Blender устанавливается отдельно от Python-зависимостей; пакет `bpy` ставить не нужно.

## Как работает наш движок

1. Claude превращает описание в JSON. Для реплики используется сцена `say`:
   персонаж `robot` или `girl`, текст, начало, конец и план `wide`, `medium` или `close`.
2. Приложение проверяет JSON и делит временную шкалу на студию и плоские вставки.
3. В фоне запускается Blender со скриптом `src/core/render3d/blender_scene.py`.
   Скрипт собирает выбранное окружение, импортирует персонажей KayKit,
   выбирает камеру и анимирует движения. Классические робот и девушка также доступны.
4. Blender сохраняет PNG-кадры студии в разрешении **810 × 1440**.
   Текст, изображения и графики готовятся отдельно через Pillow.
5. FFmpeg увеличивает кадры до **1080 × 1920**, добавляет субтитры и собирает MP4 с **30 fps**.
   Готовый файл публикуется после успешной сборки; временные кадры удаляются.

Окружения собраны из готовых ассетов: описание управляет репликами и планами камеры,
а окружение и пару персонажей можно выбрать в окне. Произвольные модели по тексту
не создаются. Озвучка выбирается отдельно: ElevenLabs или локальный Chatterbox;
если она отключена, диалог отображается субтитрами.

## Миры и персонажи KayKit

| `environment` | Окружение | Основные детали |
|---|---|---|
| `room` | Уютная комната | Мебель, места для сидения, предметы интерьера |
| `forest` | Лесная поляна | Деревья, кусты, камни и растительность |
| `dungeon` | Подземелье | Каменные стены, арки, сундуки и реквизит |
| `space` | Космическая база | Модули, оборудование и технические детали |
| `city` | Городской двор | Дома, деревья и уличные предметы |
| `studio` | Исходная студия | Робот и девушка, стол, монитор, зелёный экран |

Пять новых окружений имеют общий масштаб, одинаковые позиции ведущих и одинаковые
планы камеры. В каждом — сопоставимое количество деталей, чтобы одна локация
не выглядела пустой рядом с другой. `studio` сохранена для прежних сценариев.

Пары (`cast`): `knight_mage` — рыцарь и маг, `rogue_duo` — два разбойника,
`barbarian_mage` — варвар и маг, `ranger_knight` — лучник и рыцарь;
`classic` — исходные робот и девушка.
Для совместимости `say.who` остаётся `robot` / `girl`: это первый и второй
участник выбранной пары, а также прежние роли озвучки. Имя модели в `who` не пишут.

Окружение и пара независимы: рыцарь и маг могут говорить и в лесу, и на космобазе.
Модели хранятся локально в `assets/kaykit`; при рендере сеть не нужна.
Источники и лицензии перечислены в [assets/kaykit/README.md](../assets/kaykit/README.md).

## Запуск через окно

Выполни [быстрый старт](../README.md#быстрый-старт), установи Blender 4.2+ и FFmpeg.
Если `blender --version` не работает, укажи настоящий путь к исполняемому файлу:

```powershell
$env:WIBECODE_BLENDER = "C:\Program Files\Blender Foundation\Blender 5.2\blender.exe"
& $env:WIBECODE_BLENDER --version
.\.venv\Scripts\python.exe -m src.ui.main
```

Команды выполняются в одном PowerShell из корня проекта. Путь выше — пример:
замени его на путь к своей версии. Если окно приложения уже открыто, перезапусти его
из этого PowerShell, чтобы оно получило переменную окружения.

Выбери **3D**, окружение и пару персонажей, опиши короткий диалог, нажми **«Рендер»**.
Начни с 5–6 секунд: каждая секунда студии требует 30 отдельных кадров.
Blender открывать вручную не нужно. Путь к результату появится в строке состояния.

## Запуск из Python без Claude и API-ключа

Готовый пример с настоящим импортом KayKit, без сети:

```powershell
.\.venv\Scripts\python.exe scripts/demo_kaykit.py --environment forest --cast knight_mage --duration 4 --out outputs/kaykit-forest.mp4
```

Для другого окружения замени `forest` на `room`, `dungeon`, `space` или `city`.
При необходимости передай `--blender "C:\Program Files\Blender Foundation\Blender 5.2\blender.exe"`.
На выходе MP4 **1080 × 1920, 30 fps**, с двумя репликами и субтитрами.

Когда JSON уже готов, нужен только локальный рендер. Сохрани пример в `render_3d.py`
в корне проекта и запусти `.\.venv\Scripts\python.exe render_3d.py` из того же PowerShell:

```python
import json
from src import api

spec = api.parse_spec(json.dumps({
    "duration": 4,
    "render_mode": "3d",
    "environment": "forest",
    "cast": "knight_mage",
    "scenes": [
        {"type": "say", "who": "robot", "shot": "close",
         "text": "Привет! Это наш мир KayKit.", "start": 0, "end": 4}
    ]
}))
print(api.render_video(spec, "outputs/first-3d.mp4"))
```

Если приложение сообщает «Blender не найден», проверь PATH или `WIBECODE_BLENDER`.
Если не найден FFmpeg, проверь `ffmpeg -version` в том же PowerShell.
Поля `environment` и `cast` необязательны: старый JSON по-прежнему выбирает `studio`
и `classic`. Значения регистрозависимы; неизвестное значение вызывает `SpecError`.
