# Установка ShortsStudio в Windows

Запустите `ShortsStudio-Setup.exe`. Файлы `ShortsStudio-Setup-*.bin` должны лежать
рядом с ним: в них находится большая модель локальной озвучки.

Установка выполняется для текущего пользователя, без прав администратора.
Setup создаёт ярлыки на рабочем столе и в меню «Пуск»; удалить программу можно
через параметры приложений Windows. Настройки API и пользовательские ролики
сохраняются отдельно от установленных файлов.

Полная установка включает основной EXE, FFmpeg/ffprobe и локальную озвучку
Chatterbox Multilingual. Для неё поставляются отдельный Python 3.11, CPU PyTorch
и модель: вручную запускать pip или скачивать модель после установки не нужно.
При первом использовании озвучка загружает модель с диска и может работать
медленно на CPU. Индикатор «Озвучка…» остаётся видимым до завершения.

Выберите «Дополнительно» → «Озвучка» → «Chatterbox, локально».
Адрес нейросети и API-ключ для сценария задаются в этом же блоке.
API-ключи пользователя не входят в установщик.

Для 3D требуется отдельно установленный Blender 4.2+. Приложение находит
стандартную установку в `Program Files/Blender Foundation` автоматически;
другой путь можно задать переменной `WIBECODE_BLENDER`.

## Сборка установщика

Основная программа собирается командой `python scripts/build.py` на Python 3.11.
Она включает ресурсы, вспомогательный worker и FFmpeg/ffprobe из PATH.

Для локальной озвучки запустите `python scripts/prepare_voice.py` (нужен `uv`).
Скрипт подготавливает `build/voice-runtime/python.exe` с CPU torch/torchaudio 2.6.0
и Chatterbox, а также шесть файлов модели в `build/voice-models`.
Лицензии и происхождение файлов сохраняются вместе с ними. Модель загружается worker-процессом
через `from_local`, сетевые загрузки во время синтеза отключены.

Используется Inno Setup 6.7.3; компилятор можно установить отдельно или разместить
в `build/tools/InnoSetup/ISCC.exe`. Затем:

```powershell
.\.venv\Scripts\python.exe scripts/build_setup.py --check
.\.venv\Scripts\python.exe scripts/build_setup.py
```

Результат — `dist/setup/ShortsStudio-Setup.exe` и соседние BIN-файлы.
Для проверки отдельной установки используйте `scripts/build_setup.py --smoke`:
она имеет собственные имя, AppId и папку, чтобы не заменять обычную установку.
