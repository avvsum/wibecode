# Источники KayKit

Приложение поставляет бесплатные модели **Kay Lousberg / KayKit** локально:
во время рендера скачивание, авторизация и облачный сервис не нужны.

Состав наборов, ссылки на автора, оригинальные лицензии и пути моделей:
[assets/kaykit/README.md](../assets/kaykit/README.md).
Полная опись с SHA-256:
[assets/kaykit/manifest.json](../assets/kaykit/manifest.json).

Включены Adventurers Free 2.0, Character Animations Free 1.1,
Furniture Bits 1.0, Forest Nature Free 1.0, Dungeon Remastered 1.0,
Space Base Bits 1.0 и City Builder Bits 1.0. Их общая лицензия —
**Creative Commons Zero 1.0 Universal (CC0)**; текст из каждой оригинальной
поставки сохранён в соответствующем `assets/kaykit/<набор>/LICENSE.txt`.

Для персонажей доступны пять основных образов: Barbarian, Knight, Mage,
Ranger и Rogue; `Rogue_Hooded` — дополнительный вариант Rogue с капюшоном.
Манекены из набора анимаций предназначены для подготовки движений.
Персонажи и окружения используют один художественный стиль KayKit.

В репозитории сохранён один формат моделей — glTF/GLB с необходимыми
текстурами и бинарными буферами. Геометрия и текстуры оригинальные;
изменена только раскладка папок. Полные FBX/OBJ-дубликаты и платные наборы
не включены. Окружения приложения — авторские композиции из этих моделей.

При обновлении набора нужно сохранить оригинальную лицензию,
обновить `SOURCE.json` и пересчитать записи `manifest.json`.
В glTF проверяются относительные URI `buffers` и `images`: каждый внешний
файл должен находиться рядом с моделью по указанному пути.
