# Встроенная фоновая музыка

В каждой из семи папок уже есть короткая оригинальная инструментальная
демопетля `shorts-original.ogg`: аккорды, мелодия, бас и мягкий ритм.
Длина — 8–12 секунд; хвосты нот перенесены через границу петли.
Это процедурная музыка проекта, не музыка KayKit. Все семь треков
переданы в общественное достояние по CC0; см. [CREDITS.md](CREDITS.md).

Пересоздать треки без Python-зависимостей (нужен установленный FFmpeg):

```powershell
python scripts/generate_music.py
```

Треки лежат по настроениям: `assets/music/<mood>/*.mp3` (также `.wav`, `.ogg`, `.m4a`,
`.flac`, `.aac`). Настроения: `calm`, `upbeat`, `epic`, `lofi`, `retro`, `tense`, `happy`.
Когда модель выбирает настроение (поле `music` сценария), берётся случайный трек из его папки;
пустая папка — видео без музыки.

Класть сюда можно только музыку, которую разрешено распространять вместе с приложением
и использовать на YouTube без отчислений: CC0 / public domain или лицензия, явно разрешающая
это. Для каждого трека добавьте строку в `CREDITS.md`: название, автор, источник, лицензия.

В основном окне пункт «Свой файл…» в списке «Музыка» выбирает аудиофайл. При добавлении
музыки в ролик приложение сохраняет его копию в библиотеку пользователя
(`%APPDATA%/ShortsStudio/music`,
`~/Library/Application Support/ShortsStudio/music` или `~/.local/share/ShortsStudio/music`;
переопределяется `WIBECODE_MUSIC_DIR`). Трек доступен в списке музыки после перезапуска.
`api.import_music(path)` и кнопка «Своя музыка…» в прежнем окне также сохраняют копию в библиотеку.
